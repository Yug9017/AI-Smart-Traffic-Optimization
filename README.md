# AI Smart Traffic Optimization 🚦

AI Smart Traffic Optimization is a machine learning and computer vision-based project designed to improve traffic flow by analyzing vehicle density and dynamically optimizing traffic signal timings.

## Features

* Vehicle detection using YOLOv8
* Vehicle counting and traffic density analysis
* Dynamic traffic signal timing
* KNN-based traffic optimization
* Traffic video analysis
* Web-based dashboard

## Technologies Used

* Python
* YOLOv8
* OpenCV
* Scikit-learn
* KNN
* Flask
* React.js
* Vite

## How It Works

```text
Traffic Video
      ↓
YOLOv8 Vehicle Detection
      ↓
Vehicle Counting
      ↓
Traffic Density Analysis
      ↓
KNN Optimization
      ↓
Dynamic Traffic Signal Timing
```

## Installation

Clone the repository:

```bash
git clone https://github.com/Yug9017/AI-Drone-Traffic-Optimization.git
cd AI-Drone-Traffic-Optimization
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Run the backend:

```bash
python backend/app.py
```

Run the frontend:

```bash
cd frontend
npm install
npm run dev
```
